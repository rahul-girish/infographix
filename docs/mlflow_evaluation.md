# MLflow Tracking and Object Detection Evaluation



## Overview



This module establishes the initial experiment-tracking and object-detection evaluation framework for Infographix.



It uses:

- **MLflow** for experiment tracking, metric logging, and artifact storage.

- **pycocotools** for COCO-style bounding-box evaluation.

- **SQLite** for local MLflow tracking metadata.

- **unittest** for automated testing.



This framework is designed to evaluate model predictions independently of the model implementation.



## Environment Setup



Use Python 3.12 and activate the project virtual environment.



Install the project dependencies:



```powershell

pip install -r requirements.txt

```



## Run Automated Tests



From the repository root:



```powershell

python -m unittest discover -s src -p "test_*.py" -v

```



The tests cover:

- Perfect synthetic predictions.

- MLflow metric logging.

- Invalid bounding-box validation.

- Unknown category IDs.

- Unknown image IDs.



The current test suite contains five tests.



**Important:** The perfect-prediction test uses synthetic data. Its mAP score of 1.0 is a correctness check for the evaluation framework, not a measurement of model performance on SciPostLayout.



## Evaluate Object Detection Predictions



The evaluation function is implemented in `src/evaluation.py`.



It accepts:

- A COCO-format ground-truth JSON file.

- A JSON file containing model predictions.

- An optional output path for the evaluation report.



Predictions must use valid image and category IDs, bounding boxes in `[x, y, width, height]` format, positive bounding-box dimensions, and confidence scores between 0 and 1.



The evaluation reports:

- mAP at IoU thresholds 0.50–0.95.

- mAP at IoU 0.50.

- mAP at IoU 0.75.

- mAP for small, medium, and large objects.



Real evaluation requires ground-truth annotations and predictions generated by an actual object-detection model. Use the dataset's documented annotation format and verify its schema before running the evaluation.



## MLflow Tracking



The experiment name is `infographix-baseline`.



The evaluation logging function records evaluation parameters, metrics, and the report artifact in MLflow.



To start the local MLflow UI, run:



```powershell

mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000

```



Then open:



http://127.0.0.1:5000



Keep the terminal running while viewing the UI. Stop the server with `Ctrl+C` when finished.



The local SQLite database and MLflow artifacts are intended for local experiment tracking and should not be committed to Git.



## Current Status and Limitations



- The MLflow smoke test has been executed successfully.

- Synthetic data validates the evaluation pipeline.

- Real model performance has not yet been measured.

- Integration with the team's actual model and dataset predictions remains a subsequent step.
